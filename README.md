# 🧺 Laundry Services Web App

A simple and functional laundry services web app built as a frontend project.

This project started as a basic website, but I wanted to make it more than just a static UI. So I added service selection, cart functionality, dynamic pricing, booking and EmailJS integration.

## ✨ Features

- Browse available laundry services
- Add and remove services from cart
- Automatically calculate total price
- Booking form
- EmailJS integration for sending booking details
- Responsive design
- Simple and beginner-friendly UI

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- EmailJS
